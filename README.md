# MemoriaDinamica (Windows Forms, .NET 10)

Abrir `MemoriaDinamica.slnx` con Visual Studio 2026 (o ejecutar `dotnet run --project MemoriaDinamica`).

Pestaña 1 - Arreglos dinámicos: int[] con Array.Resize / redimensión manual y un VectorDinamico propio.
Pestaña 2 - Memoria dinámica: instancias en el Heap, alias vs clon, struct vs class, WeakReference + GC,
lista enlazada de nodos y memoria no administrada con IntPtr.
